Política de Privacidade

Última atualização: 16 de novembro de 2026.

Esta política vale para o app Gamerize Shorts, ferramenta de uso próprio da página Gamerize BR.

Quais dados o app acessa

O app usa a YouTube Data API (permissão youtube.upload) apenas para enviar vídeos ao canal da própria Gamerize BR, autorizado pelo seu dono. Ele não lê nem coleta dados de espectadores, inscritos ou de qualquer outro usuário.

Como os dados são guardados

O token de autorização do Google fica salvo somente no computador do dono do canal. Nenhum dado é enviado a servidores próprios, vendido, compartilhado ou usado para publicidade.

Uso de serviços do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O app usa os Serviços de API do YouTube; consulte também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
